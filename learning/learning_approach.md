# 🏗️ Learning Approach

This roadmap follows a **two-stage learning model**.

The objective is not only to understand a technology but also to apply it in a real-world product.

Every sprint will follow the same workflow:

Business Requirement
        ↓
Theory
        ↓
Java vs Python Comparison (when applicable)
        ↓
Hands-on Coding
        ↓
Assignment
        ↓
🧠 Daily Coding Challenge
        ↓
Quiz
        ↓
Senior Code Review
        ↓
Tech Lead Review
        ↓
Handwritten Notes
        ↓
GitHub Notes
        ↓
Interview Questions
        ↓
Wanderlust Wings Implementation
        ↓
Refactoring & Best Practices
        ↓
Git Commit & Push

## Stage 1 – Learn the Technology

Each sprint begins with a focused mini project that teaches a specific technology in isolation.

Examples:

| Sprint         | Mini Project                |
| -------------- | --------------------------- |
| Python Core    | Expense Tracker CLI         |
| Python Pro     | Travel Package Manager CLI  |
| HTML & CSS     | Portfolio Website           |
| JavaScript     | Weather Dashboard           |
| React          | Task Manager                |
| FastAPI        | Library Management API      |
| PostgreSQL     | Student Management Database |
| AI Foundations | Simple AI Chatbot           |
| RAG            | Chat with PDF               |

The purpose of these projects is to understand concepts without the complexity of a large application.

---

## Stage 2 – Apply to Wanderlust Wings

After completing the mini project, the same concepts will be implemented in the **Wanderlust Wings** platform.

Examples:

| Technology | Wanderlust Wings Feature    |
| ---------- | --------------------------- |
| Python     | Package Management          |
| HTML & CSS | Landing Page                |
| JavaScript | Package Search & Filters    |
| React      | Travel Dashboard            |
| FastAPI    | Booking APIs                |
| PostgreSQL | Travel Database             |
| AI         | AI Travel Assistant         |
| RAG        | Travel Knowledge Assistant  |
| AI Agents  | Personalized Travel Planner |

This ensures every concept learned contributes directly to building a production-ready AI travel platform.

# 💻 Engineering Workflow

Every lesson will follow this process:

1. Understand the business problem.
2. Learn the required concepts.
3. Build a focused mini project.
4. Review the code and improve it.
5. Implement the same concepts in Wanderlust Wings.
6. Commit and push the completed work.
7. Update `CURRENT_STATUS.md` and `LEARNING_LOG.md`.

# 🚀 End Goal

By following this approach, the repository will contain:

* Multiple standalone projects demonstrating individual skills.
* One complete production-style AI travel platform.
* A well-documented engineering journey from Sprint 0 to production deployment.

The goal is not just to learn technologies, but to become an engineer capable of designing, building, testing, deploying, and maintaining real-world AI applications.
